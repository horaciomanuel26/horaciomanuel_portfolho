# Horácio Manuel — Portfólio

Portfólio pessoal de **Horácio Manuel**, programador em Angola, focado em desenvolvimento web, sistemas de gestão e aplicações.

O site apresenta uma visão direta do meu percurso, stack e projectos seleccionados, com uma interface escura em tons de roxo, animações de entrada com desfoque no scroll e um fundo animado em estilo constelação.

## Visão geral

- **Foco:** programação e desenvolvimento de software
- **Stack principal:** Laravel, PHP, JavaScript, TypeScript, React Native, SQL
- **Localização:** Angola
- **Formato:** site estático (HTML, CSS e JavaScript)

## Secções

- **Hero** — apresentação, áreas de foco e links principais
- **Sobre** — resumo do meu perfil como programador
- **Trabalho** — projectos seleccionados e galeria visual
- **Stack** — tecnologias e ferramentas que utilizo
- **Contacto** — canais para conversa e colaboração

## Como executar localmente

Por ser um site estático, não precisas de instalar dependências.

1. Clona o repositório:
   ```bash
   git clone https://github.com/horaciomanuel26/horaciomanuel_portfolho.git
   ```
2. Abre a pasta do projecto.
3. Abre o ficheiro `index.html` no navegador.

> Também podes usar uma extensão como **Live Server** no VS Code para uma experiência de desenvolvimento mais cómoda.
